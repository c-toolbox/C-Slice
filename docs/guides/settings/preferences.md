# Preferences

Open **Tools > Preferences** to store startup defaults for future C-Slice jobs. Preferences do not replace the current job controls; they set the values that new sessions start with.

## Configuration defaults

Preferences store separate default SGCT files for mono/2D and stereo/3D output. Use production-specific configuration files here when most work targets the same venue.

## Location defaults

The first left-input, right-input, and output-directory locations can be saved. Empty values allow C-Slice to use standard system locations and the last-used dialog folders.

## Mapping defaults

Mapping preferences include the default surface type, dome or sphere radius, dome FOV, sphere rotation, and plane position or size.

## Encoding defaults

Encoding preferences include codec, frame rate, software and NVENC presets, tune values, bit depth, CRF, CQ, QScale, parameter JSON, and Matroska preference.

## Loading current settings

Use the Preferences dialog's runtime loading option to copy the current main-window settings into the preference fields before saving them.
