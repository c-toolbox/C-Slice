# C-Slice Version 1.0

C-Slice Version 1.0 is the first stable release of the media slicer for immersive environments.

## Release highlights

- Full support for slicing mono and stereo image sequences and video files into SGCT window outputs.
- Mapping modes for Dome, Sphere EQR, Sphere EAC, and Plane surfaces.
- Independent FFmpeg encoding per SGCT window with support for H.264, H.265, NVENC, ProRes, Hap, VP8, VP9, MPEG, PNG, JPEG, and TGA codecs.
- Video input via MPV with software, hardware, and hybrid decoding modes.
- Image Sequence Preview and Video Preview tools for verifying source content before rendering.
- Verify feature to decode-check image sequences before starting long slice jobs.
- Tools > Audio Muxer for combining mono WAV channel files into multi-channel outputs.
- Benchmark modes for performance testing without encoding or readback costs.
- Preferences system with separate defaults for mono/2D and stereo/3D workflows.
- Wuffs-enabled high-performance image loading.
- SGCT configuration file support for defining output windows, viewports, and capture settings.

## Architecture

- Built with Qt 6 and KDE Frameworks 6 using a Kirigami-based QML interface.
- Uses SGCT for window management, viewport setup, and frame capture.
- FFmpeg integration for video encoding and audio muxing.
- CMake build system with vcpkg dependency management.
